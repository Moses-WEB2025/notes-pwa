# Заметки — офлайн PWA

Нативно выглядящее приложение заметок (PWA) для iPhone и Android: работает полностью офлайн, устанавливается на домашний экран, занимает весь экран, без зума и обновления страницы — всё как у нативного приложения.

## Возможности

- **Главный экран** — masonry-сетка цветных карточек, поиск с красной подсветкой совпадений, кнопка «Отмена» при поиске, FAB «+», нижняя навигация.
- **Редактор** — заголовок, дата и счётчик символов, режимы верхней панели (обычный / при открытой клавиатуре), нижний тулбар (аудио-запись, фото, рисунок, чек-лист, заголовок), undo/redo, палитра цветов, share-меню, папки, закрепление, копирование и удаление.
- **Папки** — создание, переименование, удаление, просмотр заметок по папке.
- **Аудио** — запись с экраном волны; воспроизведение внутри заметки.
- **Рисунок** — полноэкранный редактор в стиле «Заметок» Xiaomi: бесконечный холст с точечной сеткой, пан/зум двумя пальцами, карандаш, маркер, ластик, перо, выделение, вставка фото, текста и заметок. Палитра с оттенками и полосой тона, «поднимающиеся» инструменты, undo/redo, сохранение векторного документа в IndexedDB. Рисунок вставляется в заметку и открывается повторно для продолжения.
- **Фото** — JPEG/PNG прямо в заметку.

## Запуск

Всё статическое — просто откройте `index.html` любым статик-сервером:

```bash
python -m http.server 8080
# или
npx serve .
```

Приложение работает и без сервера — просто откройте `index.html` в браузере.

## Установка на телефон

### iPhone (iOS 16.4+)
1. Откройте `https://<ваш-адрес>/` в Safari.
2. «Поделиться» → «На экран «Домой»».
3. Приложение откроется полноэкранно, без адресной строки.

### Android (Chrome)
1. Откройте `https://<ваш-адрес>/`.
2. Меню → «Установить приложение» (или «На главный экран»).
3. Запустится полноэкранно, как нативное приложение.

## Офлайн

Service Worker **полностью прекэширует** все ресурсы (HTML, CSS, JS, шрифт Material Symbols Rounded, иконки). Первый запуск требует сети; после — приложение работает без Интернета полностью.

## Данные

Хранятся локально в **IndexedDB** (заметки, папки, аудио/фото). Ничего не отправляется в сеть.

## Стек

Чистый vanilla JS (ES-модули), CSS, HTML — без сборщиков и зависимостей. Иконки — [Material Symbols Rounded](https://fonts.google.com/icons) (локальная копия).

## Структура

```
index.html          — оболочка (viewport-fit, no-zoom, no-refresh, SW-регистрация)
manifest.json       — PWA-манифест (standalone, portrait)
sw.js               — сервис-воркер (offline-first)
offline.html        — fallback-страница
styles/             — тема, стили экранов и компонентов
scripts/
  core.js           — даты, IndexedDB, навигация-стек, свайп-назад, клавиатура
  app.js            — точка входа
  main-screen.js    — главный экран
  seed.js           — демо-данные при первом запуске
  components/       — ui (диалоги, меню, sheet), recorder, drawing, drawing-art
  screens/          — editor, folders, grid
assets/
  fonts/            — Material Symbols Rounded (woff2, локально)
  icons/            — PWA-иконки 192/512
```
